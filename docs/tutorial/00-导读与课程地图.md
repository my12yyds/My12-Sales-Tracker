# 教学版导读：跟着这个项目学微信小程序 API

这套教程不是「功能文档」，而是**按 API 组织的源码导读**。

读完之后你应该能做到：看到一个 `wx.xxx` 或 `db.xxx` 调用，知道它在做什么、参数怎么传、返回值长什么样、什么情况下会坑你。所有例子都来自本仓库的真实代码，标注了文件与行号，可以边读边跳过去看。

## 为什么用这个项目学

因为它是一个**完整但不大**的项目：

- 13 个页面、16 个云函数，覆盖了小程序开发最常用的 API 面；
- 不用第三方 UI 库，`wx.showToast` 这类原生 API 直接用，看得见调用过程；
- 踩过的坑都留在代码注释和 [第 12 章](12-踩坑清单与调试.md) 里，包括分页上限、空值查重、类型不匹配这些新手最容易撞的问题；
- 有 75 项自动化测试，可以改完代码立刻验证有没有改坏。

## 怎么读

三条路线，按你的目标选：

| 你想干什么 | 建议顺序 |
| --- | --- |
| 完全新手，从零理解小程序怎么跑起来 | 01 → 02 → 03 → 05 → 06 → 09 → 10 |
| 会写页面，想搞懂云开发 | 02 → 03 → 04 → 11 |
| 手上有个类似项目要排雷 | 04 → 07 → 11 → 12 |

每章结构统一：**这个 API 是干什么的 → 本项目哪里用了 → 参数逐个说 → 容易错的地方 → 动手练习**。

## 动手之前

### 环境

1. 微信开发者工具（稳定版即可）；
2. 一个云开发环境，把 `miniprogram/app.js` 里的 `YOUR_CLOUD_ENV_ID` 换成你自己的；
3. `project.config.json` 里的 `YOUR_APPID` 换成你的 AppID（**不要提交真实值**，仓库的 CI 会检查这一点）。

### 只跑测试、不开工具

根目录不需要安装依赖，Node.js 20 以上即可：

```sh
npm test             # 75 项回归测试，用模拟 SDK 跑云函数逻辑
npm run check:syntax # 语法检查
npm run check:public # 公开配置检查（AppID / 环境 ID 是否为占位符）
```

测试里用 `vm.runInNewContext` 伪造了 `wx-server-sdk`，所以**不连真实数据库也能验证云函数逻辑**。这是本项目最值得学的一处工程实践，见 [第 11 章](11-权限模型与鉴权链路.md) 末尾。

### 改代码的建议姿势

每章末尾有练习。做练习时建议：

```sh
npm test    # 改完立刻跑，确认没破坏既有行为
```

新增行为就新增测试，别只改代码。仓库的测试文件按功能划分（`tests/lead-duplicate.test.js`、`tests/permissions.test.js` 等），照着现有写法加一条 `test()` 即可。

## 一个提醒

教程里的「上限」类数字（比如云函数单次查询最多多少条）来自官方文档与实测，**会随基础库和云开发版本变化**。涉及上限的地方我都写了「为什么要显式设 limit」的推理过程，记住推理比记住数字有用。
