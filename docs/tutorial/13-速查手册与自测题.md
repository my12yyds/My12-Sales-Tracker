# 13 速查手册与自测题

> 前 12 章按主题展开，这一章负责压缩：一张能贴在显示器边上的速查表，加一套能验证你有没有真的记住的自测题。

## 13.1 API 速查表

### 云能力

```js
// 初始化（app.js 的 onLaunch 里，只做一次）
wx.cloud.init({ env: '环境ID', traceUser: true });

// 调云函数：注意结果在 res.result
const res = await wx.cloud.callFunction({ name: '函数名', data: { ... } });
if (res.result.success) { /* res.result.data */ }

// 前端直连数据库（受权限规则约束）
const db = wx.cloud.database();

// 上传文件
const up = await wx.cloud.uploadFile({ cloudPath: 'a/b.jpg', filePath: localPath });
```

```js
// 云函数侧（每个函数开头固定三行）
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database();

// 拿可信身份
const { OPENID } = cloud.getWXContext();
```

### 数据库

```js
// 查多条 → data 是数组
const { data } = await db.collection('leads').where({ groupId: 3 }).limit(20).get();

// 查单条 → data 是对象（可能为 null）
const { data: lead } = await db.collection('leads').doc(id).get();

// 增 → 返回 { _id }
const { _id } = await db.collection('leads').add({ data: { ... } });

// 改 → 返回 { stats: { updated: n } }，n 为 0 表示没匹配到
await db.collection('leads').doc(id).update({ data: { status: 'WON' } });

// 删 → 返回 { stats: { removed: n } }
await db.collection('leads').doc(id).remove();

// 计数（不受单次上限影响）
const { total } = await db.collection('leads').where({ groupId: 3 }).count();

// 字段裁剪（白名单）
.field({ _id: true, name: true })

// 排序 + 分页
.orderBy('createdAt', 'desc').skip(20).limit(20)
```

```js
// 查询指令
const _ = db.command;
{ groupId: _.in([1, 2, 3]) }        // 属于
{ groupId: _.nin([4]) }             // 不属于
{ createdAt: _.gte(start) }         // 大于等于
{ createdAt: _.lt(end) }            // 小于
{ phone: _.exists(false) }          // 字段不存在
{ followUpCount: _.inc(1) }         // 原子自增（写操作用）

// 组合：同一字段的多个条件要拆成多个对象
_.and([{ t: _.gte(a) }, { t: _.lt(b) }])
_.or([{ phone: re }, { name: re }])

// 正则（服务端执行，无法用索引）
db.RegExp({ regexp: '张三', options: 'i' })
```

**单次 `get()` 上限**：小程序端 20 条；云函数端不传 `limit()` 时 100 条；显式 `limit()` 最多 1000 条。

## 13.2 常见需求 → 代码

| 需求 | 写法 |
| --- | --- |
| 列表分页加载 | `page` 递增，`hasMore = page * pageSize < total` |
| 搜索框不每字请求 | `bindinput` 只同步值，`bindconfirm` 或按钮才查询 |
| 防重复提交 | 状态位 `if (this.data.submitting) return;` |
| 请求竞态 | 请求序号 `this._requestId`，返回时比对 |
| 记住筛选条件 | key 带 userId + 角色，读出来先白名单清洗 |
| 未登录跳登录页 | `wx.redirectTo`（不是 navigateTo，否则能返回死循环） |
| 登录成功进主页 | `wx.reLaunch`（清空栈） |
| 提示后返回 | `setTimeout(() => wx.navigateBack(), 1500)` |
| 校验手机号 | `/^1\d{10}$/`，前后端各校验一次 |
| 导出 CSV | 加 `'\uFEFF'` BOM + `\r\n`，字段转义引号 |
| 云函数返回统一结构 | `{ success, message, data }` |
| 日期「今天」 | 手动 +8 小时再取 ISO 日期，别用 `getDate()` |

## 13.3 自测题

20 道，覆盖前 12 章的关键判断。先自己答，再点开看答案。

**1.** 云函数 `return { success: true, data: { a: 1 } }`，前端 `res` 上哪一层是它？

<details><summary>答案</summary>

`res.result`。完整响应是 `{ result, errMsg, requestID }`，业务数据在 `res.result` 里。
</details>

**2.** 云函数里 `db.collection('x').get()` 不写 `limit()`，最多返回多少条？

<details><summary>答案</summary>

100 条（云函数端）。要 1000 条必须显式 `limit(1000)`。小程序端默认是 20 条。
</details>

**3.** `doc(id).get()` 和 `where(...).get()` 的返回值有什么区别？

<details><summary>答案</summary>

`doc().get()` 的 `res.data` 是**单个对象**（查不到为 `null`）；`where().get()` 的 `res.data` 是**数组**。
</details>

**4.** 想查「今天创建的线索」，为什么不能写成一个对象 `{ createdAt: _.gte(a), createdAt: _.lt(b) }`？

<details><summary>答案</summary>

JavaScript 对象同名 key 会覆盖，最终只剩 `lt`。必须拆成两个条件对象，再用 `_.and([...])` 组合。
</details>

**5.** `wx.showLoading` 之后直接 `wx.showToast`，用户看到什么？

<details><summary>答案</summary>

还是 loading。两者共用同一块原生浮层，必须先 `wx.hideLoading()`。
</details>

**6.** 为什么「未登录跳登录页」要用 `redirectTo` 而不是 `navigateTo`？

<details><summary>答案</summary>

`navigateTo` 会保留当前页，用户在登录页按返回又回到那个页面，再次触发未登录检查、再次跳登录页，形成死循环。`redirectTo` 销毁当前页，栈里只剩登录页。
</details>

**7.** `e.target.dataset` 和 `e.currentTarget.dataset` 什么时候会不一样？

<details><summary>答案</summary>

用户点的是子元素、事件冒泡到父元素时。`target` 是实际被点的子元素（没有 `data-*`），`currentTarget` 才是绑事件的那个元素。取参数永远用 `currentTarget`。
</details>

**8.** `picker` 的 `mode="selector"`，`e.detail.value` 是什么类型？

<details><summary>答案</summary>

**字符串**形式的下标，比如 `'2'`。`array['2']` 能取到值，所以常被忽略，但 `+1` 会变成 `'21'`、`=== 2` 会为 false。
</details>

**9.** 页面 query 传的 `groupId`，在 `onLoad` 里是什么类型？

<details><summary>答案</summary>

字符串。数据库里是数字，直接拿去 `where({ groupId })` 会匹配不到。必须 `Number()`。
</details>

**10.** 本地存储读出来的数据，为什么不能直接 `setData(saved)`？

<details><summary>答案</summary>

存储内容可能来自旧版本、可能被手动改过、可能字段缺失。直接塞进 `data` 可能带进 `loading: true`（页面永远卡加载）或越界的下标（`TypeError`）。要白名单 + 类型 + 范围三重清洗。
</details>

**11.** 云函数以什么身份访问数据库？这对权限校验意味着什么？

<details><summary>答案</summary>

管理员身份，**绕过所有数据库权限规则**。所以权限必须在云函数代码里自己写全，数据库不会帮你拦。
</details>

**12.** 为什么权限测试要断言「发给数据库的查询条件」，而不只是断言返回值？

<details><summary>答案</summary>

返回值可能是巧合对了（库里恰好只有一条数据）。断言查询条件里带了 `groupId`，才能证明隔离逻辑真的生效。更严格的做法还要断言「失败时压根没发起查询」。
</details>

**13.** 接口接收了 `leadId` 参数，除了判断角色还要判断什么？

<details><summary>答案</summary>

**对象级权限**：这条线索归不归当前用户/团队。只判断「你是谁」不判断「这个对象你能不能碰」，就是 IDOR 漏洞。
</details>

**14.** `wx.setClipboardData` 之后还要不要 `showToast('已复制')`？

<details><summary>答案</summary>

不要。它自带「内容已复制」提示，重复提示反而啰嗦。
</details>

**15.** 导出 CSV 为什么要加 `'\uFEFF'`？

<details><summary>答案</summary>

UTF-8 BOM。不加的话 Excel 在中文 Windows 上按 GBK 解码，中文全是乱码。
</details>

**16.** 客户备注写成 `=1+1`，导出 CSV 后用 Excel 打开会发生什么？怎么防？

<details><summary>答案</summary>

Excel 会当公式执行。危险的是 `=HYPERLINK(...)` 这类能把同行数据外带的公式（CSV 注入）。防护：内容以 `=`、`+`、`@`、`-` 开头时前面加 `'`，强制按文本处理。
</details>

**17.** 云函数里 `new Date().getDate()` 在北京时间早上 7 点返回什么？

<details><summary>答案</summary>

云函数运行在 UTC，此时 UTC 还是前一天 23 点，所以返回的是**昨天**的日期。必须手动 +8 小时。
</details>

**18.** `Promise.all` 一次并发 100 个 `remove()` 有什么风险？

<details><summary>答案</summary>

容易撞云开发的并发/频率限制导致部分失败。建议降到 20~30。而且失败后已删的记录不会回滚。
</details>

**19.** 分页查询为什么必须加 `orderBy`？

<details><summary>答案</summary>

不排序时数据库返回顺序不保证稳定，翻页可能出现重复或漏数据。
</details>

**20.** 一个云函数「改了但没生效」，最可能的原因？

<details><summary>答案</summary>

没重新上传部署。保存文件 ≠ 部署，云函数是独立部署单元。加一句版本日志去控制台确认。
</details>

## 13.4 如果只能记住五条

1. **结果在 `res.result`**，不是 `res`。
2. **`.get()` 有上限**，要全量就分页。
3. **身份来自 `getWXContext().OPENID`**，前端传的任何身份都不可信。
4. **`hideLoading` 要在 `showToast` 之前**。
5. **云函数是 UTC**，日期要手动 +8 小时。
